3-Macaw Speech는 휴대폰에서 음성 인식, 호출어 감지, 음성 합성을 오프라인으로 처리하며, 모델을 내려받은 뒤에는 모든 계산이 기기 안에서 이루어져 음성이 업로드되지 않습니다. AutoJs6 없이도 단독으로 쓸 수 있고, 시스템 텍스트 음성 변환 엔진, 음성 입력, 디지털 어시스턴트로도 쓸 수 있습니다. AutoJs6와 함께 쓰면 스크립트에서 받아쓰기, 오디오 파일 인식, 호출어 대기, 텍스트 읽기를 할 수 있습니다.

### 시작하기

1. 3-Macaw Speech를 열고 홈 화면의 "마이크 권한" 줄에서 "허용"을 탭합니다.
2. 홈 화면의 "음성 인식", "호출어", "음성 합성" 그룹에서 필요한 모델을 내려받습니다. "추천" 표시가 있는 모델로 시작하면 좋습니다.
3. 홈 화면의 "체험하기" 버튼을 탭해 받아쓰기, 호출어, 음성 합성을 시험해 봅니다.
4. 스크립트에서 사용하려면 AutoJs6의 "플러그인 센터"에서 이 플러그인을 활성화합니다.

### 주요 기능

- **음성 인식**: 마이크 음성을 실시간으로 받아쓰고, 오디오 파일과 동영상 속 소리도 인식합니다. 중국어, 영어, 일본어, 광둥어 등의 오프라인 모델을 제공하며, "문장 부호" 모델을 내려받으면 결과에 문장 부호가 자동으로 붙습니다.
- **호출어**: 키워드를 그대로 입력하면 되고 모델 학습은 필요 없습니다. 호출어를 들은 뒤 이어서 한 문장을 받아쓸 수 있습니다.
- **음성 합성**: 신경망 음성으로 텍스트를 읽어 주거나 오디오 파일로 합성합니다. 시스템 텍스트 음성 변환 엔진으로 설정하면 AutoJs6의 `tts` 모듈과 다른 앱도 이것으로 읽어 줍니다.
- **음성 입력과 디지털 어시스턴트**: 다른 앱의 마이크 버튼에서 오프라인으로 받아쓸 수 있습니다. 기본 디지털 어시스턴트로 설정하면 전원 키나 Home 키를 길게 눌러 한 문장을 말하고, 그 텍스트를 음성 명령을 받는 앱에 넘길 수 있습니다.
- **실행 방법**: "빠른 설정 타일", "홈 화면 위젯과 바로가기", "플로팅 마이크" 등의 입구에서 같은 받아쓰기 패널을 열 수 있으며, 평소에는 녹음하지 않습니다.
- **상시 호출어**: 기본값은 꺼짐입니다. 켜면 호출어를 말할 때 받아쓰기 패널이 열리고, 호출어마다 "브로드캐스트 전송" 또는 "알림만"으로 바꿀 수도 있습니다. 켜져 있는 동안 마이크 표시등이 계속 켜지고 배터리도 더 소모됩니다.
- **화자 인식**: "화자" 페이지에서 자신의 목소리를 등록하고 "등록된 목소리만"을 켜면, 상시 호출어가 등록된 사람에게만 반응합니다.
- **파일 변환과 분석**: "체험하기"의 "파일" 탭에서 오디오를 텍스트로 바꾸고 "자막으로 저장"할 수 있으며, 화자 분리, 언어 식별, 소리 태그 지정도 할 수 있습니다.
- **모델 관리**: 모델은 파일마다 검증을 마친 뒤에 사용됩니다. 새 버전이 나오면 모델 카드에서 바로 업데이트할 수 있고, "로컬 모델 가져오기"도 쓸 수 있습니다.
- **플러그인 도구**: MCP Server 플러그인이나 `plugins.tools.call`로 한 문장 듣기, 텍스트 읽기, 오디오 파일 인식을 할 수 있습니다.

### 스크립트에서 사용하기

AutoJs6의 Rhino 스크립트에서는 전역 모듈 `speech`로 이 기능들을 사용합니다. 실행하기 전에 호출어, 음성 인식, 음성 합성 모델을 내려받아 두세요. 다음 예제는 호출어를 들은 뒤 한 문장을 듣고, 인식한 텍스트를 출력하고 읽어 줍니다:

```js
let wake = speech.wake(["hey macaw", "小六小六"], { thenListen: true });
wake.on("wake", e => {
    e.listen.on("final", r => {
        console.log(r.text);
        speech.speak(r.text);
    });
});
```

- `speech.recognize`는 오디오 파일을 텍스트로 인식하고 `speech.synthesize`는 텍스트를 WAV 파일로 합성합니다. 둘 다 블로킹 방식이라 UI 스레드에서 호출할 수 없으므로, UI 스크립트에서는 `recognizeAsync`와 `synthesizeAsync`를 사용하세요.
- 받아쓰기나 호출어 세션은 한 번에 하나만 열 수 있으며, 하나 더 열면 대기하지 않고 `SESSION_BUSY`로 실패합니다.
- Node.js 스크립트는 `autojs6:speech`로 같은 API를 사용하고, Bun 스크립트는 `host.speech`를 사용하며 `speech.control` 권한 부여가 필요합니다.
- 화자 인식, 오디오 분석, 모델 관리 등 전체 사용법은 [AutoJs6 문서 > speech](https://docs.autojs6.com/#/speech)를 참고하세요.

### 요구 사항

- Android 7.0 이상. 플러그인 화면, 시스템 텍스트 음성 변환 엔진, 음성 입력, 디지털 어시스턴트에는 AutoJs6가 필요하지 않습니다.
- `speech` 모듈과 플러그인 도구에는 AutoJs6 6.8.0 이상이 필요하며, "플러그인 센터"에서 이 플러그인을 활성화해야 합니다.
- 마이크 권한은 받아쓰기와 호출어 감지에 쓰이며 이 플러그인에 직접 허용해야 합니다. AutoJs6의 마이크 권한으로는 대신할 수 없습니다. 알림 권한은 모델 다운로드 진행률 표시에 쓰입니다.
- 다른 앱 위에 표시 권한은 선택 사항이며, "플로팅 마이크"와 상시 호출어가 백그라운드에서 바로 받아쓰기 패널을 여는 데 쓰입니다. "키 트리거"는 시스템 접근성 설정에서 켜야 하며, 키만 걸러 낼 뿐 화면 내용은 읽지 않습니다.
- 모델은 인터넷으로 내려받으며 하나에 몇 MB에서 몇백 MB까지입니다. 내려받은 뒤에는 인식과 합성이 오프라인으로 동작합니다.

### 자주 묻는 질문

**시스템 기본 텍스트 음성 변환 엔진으로 설정하는 방법**

홈 화면의 "시스템 텍스트 음성 변환 엔진" 줄에서 "설정 열기"를 탭하고, 시스템 화면에서 기본 엔진을 3-Macaw Speech로 설정합니다. 엔진은 설치된 합성 모델이 지원하는 언어만 제공하므로, 미리 듣기에서 소리가 나지 않으면 기기 언어를 지원하는 합성 모델을 먼저 내려받으세요.

**상시 호출어 사용 중 마이크 표시등이 계속 켜져 있는 이유**

호출어를 기다리려면 계속 녹음해야 하며, Android 12부터는 그동안 상태 표시줄에 마이크 표시등이 계속 나타나고 앱에서 숨길 수 없습니다. 설정에서 "듣기 시간"을 제한하거나 "충전 중에만 듣기"를 켜는 것을 권장합니다.

**모델 다운로드에 실패할 때의 조치**

플러그인은 먼저 GitHub에서 내려받고, 실패하면 자동으로 업스트림 주소로 바꿉니다. 중단된 다운로드는 이어서 받을 수 있습니다. 그래도 내려받을 수 없으면 다른 기기에서 모델 압축 파일을 내려받은 뒤 홈 화면의 "로컬 모델 가져오기"로 가져오세요.

**스크립트의 첫 받아쓰기에서 기다려야 하는 이유**

플러그인은 유휴 모델을 해제하므로, 그 뒤 첫 받아쓰기에서는 모델을 다시 불러와야 하며 오래된 휴대폰에서는 몇 초가 걸릴 수 있습니다. 설정에서 "유휴 모델 해제"를 "해제 안 함"으로 바꾸면 기다리지 않아도 되지만, 메모리를 계속 차지합니다.

모델 목록, 각 입구의 설정 방법, 더 많은 자주 묻는 질문은 [프로젝트 페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Macaw-Speech)를 참고하세요.
