3-Macaw Speech 在手機上離線完成語音識別, 喚醒詞檢測與語音合成, 下載模型後全部運算都在本機進行, 音訊不會上傳. 不裝 AutoJs6 也能獨立使用, 還可以作為系統的文字轉語音引擎, 語音輸入與數碼助理. 配合 AutoJs6 時, 腳本可以聽寫, 識別音訊檔案, 等待喚醒詞與朗讀文字.

### 開始使用

1. 開啟 3-Macaw Speech, 在首頁 "麥克風權限" 一行點按 "授權".
2. 在首頁的 "語音識別", "喚醒詞" 與 "語音合成" 分組中下載需要的模型, 標有 "推薦" 的模型是較好的起點.
3. 點按首頁的 "試聽試說" 按鈕, 試一試聽寫, 喚醒詞與合成.
4. 需要在腳本中使用時, 在 AutoJs6 的 "插件中心" 啟用本插件.

### 主要功能

- **語音識別**: 實時聽寫麥克風中的語音, 也可以識別音訊檔案與影片中的聲音; 提供中文, 英文, 日語, 粵語等語言的離線模型. 下載 "標點" 模型後, 結果會自動加上標點.
- **喚醒詞**: 直接填寫關鍵詞原文, 無須訓練模型; 聽到喚醒詞後可以接著聽寫一句話.
- **語音合成**: 用神經網絡聲音朗讀文字或合成為音訊檔案; 作為系統文字轉語音引擎時, AutoJs6 的 `tts` 模組和其他應用程式也能用它朗讀.
- **語音輸入與數碼助理**: 其他應用程式的麥克風按鈕可以用它離線聽寫; 設為預設數碼助理後, 長按電源鍵或 Home 鍵說一句話, 文字交給接收語音指令的應用程式.
- **觸發方式**: "快速設定圖塊", "主畫面小工具與捷徑", "懸浮麥克風" 等入口都能開啟同一個聽寫面板, 平時不錄音.
- **常駐喚醒**: 預設關閉; 開啟後說出喚醒詞即開啟聽寫面板, 也可以讓某個喚醒詞 "發送系統廣播" 或 "只發通知". 開啟期間麥克風指示燈常亮, 也更耗電.
- **說話人識別**: 在 "說話人" 頁登記自己的聲音後開啟 "只聽主人", 常駐喚醒只回應已登記的人.
- **檔案轉寫與分析**: "試聽試說" 的 "檔案" 頁可以把音訊轉成文字並 "儲存為字幕", 還能分離說話人, 識別語種與為聲音加標籤.
- **模型管理**: 模型逐個檔案校驗後才啟用, 有新版本時在模型卡片上即可更新, 也可以 "匯入本機模型".
- **插件工具**: 透過 MCP Server 插件或 `plugins.tools.call` 聽一句話, 朗讀文字與識別音訊檔案.

### 在腳本中使用

在 AutoJs6 的 Rhino 腳本中透過全域模組 `speech` 使用這些功能, 運行前先下載喚醒詞, 語音識別與語音合成模型. 下例聽到喚醒詞後聽一句話, 輸出並朗讀識別出的文字:

```js
let wake = speech.wake(["hey macaw", "小六小六"], { thenListen: true });
wake.on("wake", e => {
    e.listen.on("final", r => {
        console.log(r.text);
        speech.speak(r.text);
    });
});
```

- `speech.recognize` 把音訊檔案識別成文字, `speech.synthesize` 把文字合成為 WAV 檔案; 兩者都會阻塞, 不能在 UI 線程調用, 介面腳本中改用 `recognizeAsync` 與 `synthesizeAsync`.
- 同一時間只能開啟一個聽寫或喚醒會話, 再開啟一個會以 `SESSION_BUSY` 失敗, 不會排隊.
- Node.js 腳本透過 `autojs6:speech` 使用同一套接口; Bun 腳本透過 `host.speech` 使用, 需要 `speech.control` 授權.
- 說話人識別, 音訊分析與模型管理等完整用法見 [AutoJs6 文檔 > speech](https://docs.autojs6.com/#/speech).

### 運行要求

- Android 7.0 或更高版本. 插件介面, 系統文字轉語音引擎, 語音輸入與數碼助理不需要 AutoJs6.
- `speech` 模組與插件工具需要 AutoJs6 6.8.0 或更高版本, 並在 "插件中心" 啟用本插件.
- 麥克風權限用於聽寫與喚醒詞檢測, 需要授予本插件, AutoJs6 的麥克風權限不能代替; 通知權限用於顯示模型下載進度.
- 懸浮視窗權限為可選, 用於 "懸浮麥克風" 與常駐喚醒在後台直接開啟聽寫面板; "按鍵觸發" 需要在系統無障礙設定中開啟, 只過濾按鍵, 不讀取螢幕內容.
- 模型需要上網下載, 每個由幾 MB 到幾百 MB 不等; 下載後識別與合成不再需要上網.

### 常見問題

**設為系統預設文字轉語音引擎的方法**

點按首頁 "系統文字轉語音引擎" 一行的 "開啟設定", 在系統頁面中把首選引擎設為 3-Macaw Speech. 引擎只提供已安裝的合成模型所涵蓋的語言, 試聽沒有聲音時先下載涵蓋裝置語言的合成模型.

**常駐喚醒時麥克風指示燈常亮的原因**

持續監聽喚醒詞需要一直錄音, Android 12 起狀態欄會一直顯示麥克風指示燈, 應用程式無法隱藏. 建議在設定中限定 "監聽時長" 或開啟 "只在充電時監聽".

**下載模型失敗時的處理**

插件優先從 GitHub 下載, 失敗時自動改用上游地址, 中斷的下載可以繼續. 仍然無法下載時, 在其他裝置下載模型壓縮檔, 再用首頁的 "匯入本機模型" 匯入.

**腳本第一次聽寫需要等待的原因**

插件會釋放閒置的模型, 之後第一次聽寫要重新載入, 較舊的手機上可能需要幾秒. 在設定中把 "閒置模型釋放" 設為 "不釋放" 可以省去等待, 代價是一直佔用記憶體.

模型列表, 各入口的設定方法與更多常見問題見 [項目主頁](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Macaw-Speech).
