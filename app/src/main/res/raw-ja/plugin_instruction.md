3-Macaw Speech は [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) を使い, 音声認識, 音声区間検出, ウェイクワード検出, ニューラル音声合成をデバイス上でオフライン実行します. すべての処理は端末内で行われ, 音声がアップロードされることはありません.

> スクリプトで `speech` モジュールを使うには AutoJs6 6.8.0 (内部バージョン 5456) 以降が必要です. システムのテキスト読み上げエンジン, システムの音声入力, 音声認識サービス, デジタルアシスタントとプラグイン自身の画面は AutoJs6 に依存せず, プラグインをインストールしてモデルをダウンロードすれば使えます.

### 機能ハイライト

- 音声認識: マイクからのストリーミング書き起こし (途中結果と確定結果をリアルタイムに返す) と音声ファイルの認識 (WAV, MP3, AAC, Ogg, FLAC など. 動画ファイルの音声も可). 中国語, 英語, 中英混在, 日本語, 韓国語, 広東語のオフラインモデルを提供します. フランス語, ロシア語, 韓国語には話しながら文字が出るストリーミングモデルもあります. 1.3.0 ではスペイン語のオフラインモデル (句読点付き) と, 言語を自動で判別する 8 言語のストリーミングモデル (アラビア語, インドネシア語, タイ語, ベトナム語, 日本語, ロシア語, 中国語, 英語) を追加しました.
- 自動句読点: 句読点モデルをインストールすると, ストリーミングモデルが認識した各文に読点, 句点, 疑問符が付き (中国語と英語), 英語は大文字も復元されます. SenseVoice は自前の句読点を付けるため変わりません. 句読点モデルはホーム画面の "句読点" グループからダウンロードします.
- 音声区間検出: 内蔵の silero VAD v5 が音声を発話区間に分割し, 書き起こし時の自動的な文の区切りにも使われます.
- ウェイクワード: キーワードをそのまま入力するだけ (例: `小六小六` や `hey macaw`) でモデルの学習は不要です. 起動後は自動的に書き起こしへ移行できます.
- 音声合成: 複数の中国語と英語のニューラル音声. WAV ファイルへ合成できるほか, システム TTS エンジンとして AutoJs6 の `tts` モジュールや他のアプリから使えます. フランス語, スペイン語, ドイツ語, ロシア語の Piper 音声もあります (非商用のみ). 1.3.0 では Kokoro v1.0 の多言語音声 (英語, スペイン語, フランス語, ヒンディー語, イタリア語, ブラジルポルトガル語, 中国語) と, アラビア語と韓国語の音声 (非商用のみ) を追加しました.
- システムの音声入力: 他のアプリ (3-Stove Agent など) のマイクボタンでオフライン認識を使えます. 画面下部のパネルで一文を話すと, 認識されたテキストがそのアプリに戻ります.
- デジタルアシスタント: 3-Macaw Speech をデフォルトのデジタルアシスタントアプリに選ぶと, 電源ボタンまたはホームボタンの長押しで一文を話し, 必要なら認識されたテキストを編集して 3-Stove Agent や 3-Stone AI など音声コマンドを受け取るアプリに渡すか, コピーできます. システムの音声認識サービスも提供します. Android 11 以前ではアシスタントに選ぶと通常はデフォルトの音声認識サービスにもなり, Android 12 以降はシステムの音声入力設定で別途選びます (この設定がない端末もあります). アプリが直接指定することもできます.
- 起動方法: 電源ボタンを長押ししなくても同じ音声入力パネルを開けます: クイック設定タイル (ロック画面でも使えます), ホーム画面のウィジェットとアプリアイコンのショートカット, ドラッグできるフローティングマイク (デフォルトはオフ), 音量キーの長押しまたは 2 回押しで開くキートリガー (キー操作だけを扱うユーザー補助サービス, デフォルトはオフ), Bluetooth ヘッドセットの音声キー. 普段は録音せず, マイクを使うのはパネルで話している数秒間だけです.
- 常時ウェイクワード (既定はオフ): オンにすると, ウェイクワード (既定は `小鹦小鹦` と `Hey Macaw`. 変更可) を言うだけで同じ音声入力パネルが開き, 画面オフやロック中も画面が点灯し, 認識した文字を読み上げます. 待ち受け中はマイクのインジケーターが点灯し続け, 通知が常に表示され, 電池の消費も増えます (既定でオンの省電力モードは静かな間ウェイクワードのモデルを動かさないので, CPU の使用がずっと少なくなります). 待ち受け時間 (10, 30, 60 分後に自動でオフ, または常にオン) と充電中のみ待ち受けを設定できます. スクリプト, 他のアプリ, 他の起動方法がマイクを使うときはいったん譲り, 終わると再開します.
- プラグインツール (AutoJs6 6.8.0 以降): `speech_listen` (一文を聞き取って認識したテキストを返す), `speech_speak` (テキストを読み上げる), `speech_transcribe` (スマートフォン上の音声ファイルを書き起こす), `speech_synthesize` (テキストを WAV または M4A ファイルに合成する) の 4 つのツールを提供します. MCP Server プラグインはこれらを使って, パソコン上の AI アシスタントがスマートフォンを通じて聞いたり話したりできるようにします. スクリプトからも `plugins.tools` で呼び出せます.
- モデル管理: 署名付きモデルカタログからダウンロードし, ファイルごとに SHA-256 を検証してから有効化します. ローカルモデルのインポートにも対応します. 非商用に限られるモデルはダウンロード前にライセンスを表示します.
- 独立した画面: ホーム画面で状態を表示してモデルを管理し, お試し画面で書き起こし, ウェイクワード, 合成を直接試せるほか, 端末の音声ファイルや動画ファイルを文字に起こしてテキストや SRT 字幕として保存でき, 設定で言語, ナイトモード, テーマカラー, ランチャーアイコン, 認識と合成のデフォルトを変更します. 外観はデフォルトで AutoJs6 に従います.

### インストールと使い方

1. [Releases](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Macaw-Speech/releases) からデバイスの ABI に合った APK をダウンロードしてインストールします. ほとんどのスマートフォンは `arm64-v8a` です. 不明な場合は, すべてのデバイスで動作するもののサイズが大きい `universal` を選びます.
2. 3-Macaw Speech を開き, ホーム画面でマイクの権限を許可して, 認識, ウェイクワード, 合成の各グループで必要なモデルをダウンロードします (カタログの推奨モデルから始めるのがおすすめです. 下記のモデル表を参照). Android 13 以降では最初のダウンロード時にダウンロード進捗の通知の表示も求められます.
3. AutoJs6 で使う: AutoJs6 を 6.8.0 (内部バージョン 5456) 以降に更新し, プラグインセンターで 3-Macaw Speech を有効にして, スクリプトから `speech` モジュールを呼び出します (下記のスクリプト API を参照). AutoJs6 のサンプル > 3-Macaw Speech にすぐに実行できる 4 つのサンプルがあります.
4. 他のアプリで使う: システムのテキスト読み上げエンジンは下記のシステムのテキスト読み上げ設定を, システムの音声入力, 音声認識サービス, デジタルアシスタントはよくある質問を参照してください.

詳しい使い方, モデルの一覧, よくある質問は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Macaw-Speech) を, スクリプト API は [AutoJs6 ドキュメント](https://docs.autojs6.com/#/speech) を参照してください.
