3-Macaw Speech は音声認識, ウェイクワード検出, 音声合成をスマートフォン上でオフラインで行い, モデルのダウンロード後はすべての処理が端末内で完結するため, 音声がアップロードされることはありません. AutoJs6 がなくても単独で使え, システムのテキスト読み上げエンジン, 音声入力, デジタルアシスタントとしても使えます. AutoJs6 と組み合わせると, スクリプトから音声入力, 音声ファイルの文字起こし, ウェイクワードの待ち受け, テキストの読み上げができます.

### はじめに

1. 3-Macaw Speech を開き, ホーム画面の "マイクの権限" の行で "許可" をタップします.
2. ホーム画面の "音声認識", "ウェイクワード", "音声合成" のグループで必要なモデルをダウンロードします. "おすすめ" の付いたモデルから始めるのがよいでしょう.
3. ホーム画面の "お試し" ボタンをタップし, 音声入力, ウェイクワード, 音声合成を試します.
4. スクリプトで使うときは, AutoJs6 の "プラグインセンター" でこのプラグインを有効にします.

### 主な機能

- **音声認識**: マイクの音声をリアルタイムで書き起こすほか, 音声ファイルや動画の音声も文字にできます. 中国語, 英語, 日本語, 広東語などのオフラインモデルがあり, "句読点" モデルをダウンロードすると結果に句読点が自動で付きます.
- **ウェイクワード**: キーワードをそのまま入力するだけで, モデルの学習は不要です. ウェイクワードを聞き取った後, 続けて一文を書き起こせます.
- **音声合成**: ニューラル音声でテキストを読み上げたり, 音声ファイルに合成したりします. システムのテキスト読み上げエンジンにすると, AutoJs6 の `tts` モジュールや他のアプリもこれで読み上げられます.
- **音声入力とデジタルアシスタント**: 他のアプリのマイクボタンからオフラインで音声入力できます. 既定のデジタルアシスタントにすると, 電源キーか Home キーの長押しで一言話し, その文字を音声コマンドを受け付けるアプリに渡せます.
- **起動方法**: "クイック設定タイル", "ホーム画面のウィジェットとショートカット", "フローティングマイク" などの入口から同じ音声入力パネルを開けます. 普段は録音しません.
- **常時ウェイクワード**: 既定ではオフです. オンにするとウェイクワードで音声入力パネルが開き, ウェイクワードごとに "ブロードキャストを送信" または "通知のみ" に変えることもできます. オンの間はマイクのインジケーターが点灯し続け, 電池の消費も増えます.
- **話者認識**: "話者" ページで自分の声を登録して "登録した声だけ" をオンにすると, 常時ウェイクワードは登録した人にだけ反応します.
- **ファイルの文字起こしと分析**: "お試し" の "ファイル" タブで音声を文字にして "字幕として保存" できるほか, 話者の分離, 言語の判定, 音の分類もできます.
- **モデル管理**: モデルはファイルごとに検証してから有効になります. 新しいバージョンが出るとモデルカードからすぐ更新でき, "ローカルモデルをインポート" も使えます.
- **プラグインツール**: MCP Server プラグインや `plugins.tools.call` から, 一文の聞き取り, テキストの読み上げ, 音声ファイルの文字起こしができます.

### スクリプトでの使い方

AutoJs6 の Rhino スクリプトでは, グローバルモジュール `speech` でこれらの機能を使います. 実行前にウェイクワード, 音声認識, 音声合成のモデルをダウンロードしておいてください. 次の例はウェイクワードを聞き取った後に一文を聞き取り, 認識した文字を出力して読み上げます:

```js
let wake = speech.wake(["hey macaw", "小六小六"], { thenListen: true });
wake.on("wake", e => {
    e.listen.on("final", r => {
        console.log(r.text);
        speech.speak(r.text);
    });
});
```

- `speech.recognize` は音声ファイルを文字にし, `speech.synthesize` はテキストを WAV ファイルに合成します. どちらもブロックするため UI スレッドでは呼び出せません. UI スクリプトでは `recognizeAsync` と `synthesizeAsync` を使ってください.
- 同時に開ける音声入力またはウェイクワードのセッションは 1 つだけで, もう 1 つ開こうとすると順番待ちせずに `SESSION_BUSY` で失敗します.
- Node.js スクリプトは `autojs6:speech` で同じ API を使えます. Bun スクリプトは `host.speech` を使い, `speech.control` の許可が必要です.
- 話者認識, 音声分析, モデル管理などの詳しい使い方は [AutoJs6 ドキュメント > speech](https://docs.autojs6.com/#/speech) を参照してください.

### 動作要件

- Android 7.0 以降. プラグインの画面, システムのテキスト読み上げエンジン, 音声入力, デジタルアシスタントには AutoJs6 は不要です.
- `speech` モジュールとプラグインツールには AutoJs6 6.8.0 以降が必要で, "プラグインセンター" でこのプラグインを有効にする必要があります.
- マイクの権限は音声入力とウェイクワード検出に使い, このプラグイン自体に許可する必要があります. AutoJs6 のマイク権限では代わりになりません. 通知の権限はモデルのダウンロード進捗の表示に使います.
- オーバーレイ権限は任意で, "フローティングマイク" と常時ウェイクワードがバックグラウンドから直接音声入力パネルを開くために使います. "キートリガー" はシステムのユーザー補助設定でオンにする必要があり, キー入力を絞り込むだけで画面の内容は読み取りません.
- モデルはインターネットからダウンロードし, 1 つあたり数 MB から数百 MB です. ダウンロード後は認識も合成もオフラインで動作します.

### よくある質問

**システムの既定のテキスト読み上げエンジンにする方法**

ホーム画面の "システムのテキスト読み上げエンジン" の行で "設定を開く" をタップし, システムの画面で優先するエンジンを 3-Macaw Speech にします. エンジンが提供するのはインストール済みの合成モデルが対応する言語だけなので, 試聴で音が出ないときは端末の言語に対応する合成モデルを先にダウンロードしてください.

**常時ウェイクワードでマイクのインジケーターが点灯し続ける理由**

ウェイクワードを待ち受けるには録音し続ける必要があり, Android 12 以降はその間ステータスバーにマイクのインジケーターが表示され続け, アプリからは消せません. 設定で "待ち受け時間" を制限するか, "充電中のみ待ち受け" をオンにすることをおすすめします.

**モデルのダウンロードに失敗する場合の対処**

プラグインはまず GitHub からダウンロードし, 失敗すると自動的にアップストリームのアドレスに切り替えます. 中断したダウンロードは続きから再開できます. それでもダウンロードできないときは, 別の端末でモデルのアーカイブをダウンロードし, ホーム画面の "ローカルモデルをインポート" で取り込んでください.

**スクリプトの最初の音声入力で待たされる理由**

プラグインは使われていないモデルを解放するため, その後の最初の音声入力ではモデルを読み込み直す必要があり, 古いスマートフォンでは数秒かかることがあります. 設定で "未使用のモデルを解放" を "解放しない" にすると待ち時間はなくなりますが, メモリを使い続けます.

モデルの一覧, 各入口の設定方法, その他のよくある質問は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Macaw-Speech) を参照してください.
