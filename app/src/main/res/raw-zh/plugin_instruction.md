3-Macaw Speech 在手机上离线完成语音识别, 唤醒词检测与语音合成, 下载模型后全部计算都在本机进行, 音频不会上传. 不装 AutoJs6 也能单独使用, 还可以作为系统的文字转语音引擎, 语音输入与数字助理. 配合 AutoJs6 时, 脚本可以听写, 识别音频文件, 等待唤醒词与朗读文字.

### 开始使用

1. 打开 3-Macaw Speech, 在首页 "麦克风权限" 一行点按 "授权".
2. 在首页的 "语音识别", "唤醒词" 与 "语音合成" 分组中下载需要的模型, 标有 "推荐" 的模型是较好的起点.
3. 点按首页的 "试听试说" 按钮, 试一试听写, 唤醒词与合成.
4. 需要在脚本中使用时, 在 AutoJs6 的 "插件中心" 启用本插件.

### 主要功能

- **语音识别**: 实时听写麦克风中的语音, 也可以识别音频文件与视频中的声音; 提供中文, 英文, 日语, 粤语等语言的离线模型. 下载 "标点" 模型后, 结果会自动加上标点.
- **唤醒词**: 直接填写关键词原文, 无需训练模型; 听到唤醒词后可以接着听写一句话.
- **语音合成**: 用神经网络声音朗读文字或合成为音频文件; 作为系统文字转语音引擎时, AutoJs6 的 `tts` 模块和其他应用也能用它朗读.
- **语音输入与数字助理**: 其他应用的麦克风按钮可以用它离线听写; 设为默认数字助理后, 长按电源键或 Home 键说一句话, 文字交给接收语音指令的应用.
- **触发方式**: "快速设置磁贴", "桌面小部件与快捷方式", "悬浮麦克风" 等入口都能打开同一个听写弹层, 平时不录音.
- **常驻唤醒**: 默认关闭; 开启后说出唤醒词即打开听写弹层, 也可以让某个唤醒词 "发系统广播" 或 "只通知". 开启期间麦克风指示灯常亮, 也更耗电.
- **说话人识别**: 在 "说话人" 页注册自己的声音后打开 "只听主人", 常驻唤醒只响应已注册的人.
- **文件转写与分析**: "试听试说" 的 "文件" 页可以把音频转成文字并 "保存为字幕", 还能分离说话人, 识别语种与给声音打标签.
- **模型管理**: 模型逐个文件校验后才启用, 有新版本时在模型卡片上即可更新, 也可以 "导入本地模型".
- **插件工具**: 通过 MCP Server 插件或 `plugins.tools.call` 听一句话, 朗读文字与识别音频文件.

### 在脚本中使用

在 AutoJs6 的 Rhino 脚本中通过全局模块 `speech` 使用这些能力, 运行前先下载唤醒词, 语音识别与语音合成模型. 下例听到唤醒词后听一句话, 打印并朗读识别出的文字:

```js
let wake = speech.wake(["hey macaw", "小六小六"], { thenListen: true });
wake.on("wake", e => {
    e.listen.on("final", r => {
        console.log(r.text);
        speech.speak(r.text);
    });
});
```

- `speech.recognize` 把音频文件识别成文字, `speech.synthesize` 把文字合成为 WAV 文件; 两者都会阻塞, 不能在 UI 线程调用, 界面脚本中改用 `recognizeAsync` 与 `synthesizeAsync`.
- 同一时间只能打开一个听写或唤醒会话, 再打开一个会以 `SESSION_BUSY` 失败, 不会排队.
- Node.js 脚本通过 `autojs6:speech` 使用同一套接口; Bun 脚本通过 `host.speech` 使用, 需要 `speech.control` 授权.
- 说话人识别, 音频分析与模型管理等完整用法见 [AutoJs6 文档 > speech](https://docs.autojs6.com/#/speech).

### 运行要求

- Android 7.0 或更高版本. 插件界面, 系统文字转语音引擎, 语音输入与数字助理不需要 AutoJs6.
- `speech` 模块与插件工具需要 AutoJs6 6.8.0 或更高版本, 并在 "插件中心" 启用本插件.
- 麦克风权限用于听写与唤醒词检测, 需要授予本插件, AutoJs6 的麦克风权限不能代替; 通知权限用于显示模型下载进度.
- 悬浮窗权限为可选, 用于 "悬浮麦克风" 与常驻唤醒在后台直接打开听写弹层; "按键触发" 需要在系统无障碍设置中开启, 只过滤按键, 不读取屏幕内容.
- 模型需要联网下载, 每个几 MB 到几百 MB 不等; 下载后识别与合成不再联网.

### 常见问题

**设为系统默认文字转语音引擎的方法**

点按首页 "系统文字转语音引擎" 一行的 "打开设置", 在系统页面中把首选引擎设为 3-Macaw Speech. 引擎只提供已安装的合成模型所覆盖的语言, 试听没有声音时先下载覆盖设备语言的合成模型.

**常驻唤醒时麦克风指示灯常亮的原因**

持续监听唤醒词需要一直录音, Android 12 起状态栏会一直显示麦克风指示灯, 应用无法隐藏. 建议在设置中限定 "监听时长" 或打开 "只在充电时监听".

**下载模型失败时的处理**

插件优先从 GitHub 下载, 失败时自动改用上游地址, 中断的下载可以继续. 仍无法下载时, 在其他设备下载模型归档, 再用首页的 "导入本地模型" 导入.

**脚本第一次听写需要等待的原因**

插件会释放空闲的模型, 之后第一次听写要重新加载, 较旧的手机上可能需要几秒. 在设置中把 "空闲模型释放" 设为 "不释放" 可以省去等待, 代价是一直占用内存.

模型列表, 各入口的设置方法与更多常见问题见 [项目主页](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Macaw-Speech).
