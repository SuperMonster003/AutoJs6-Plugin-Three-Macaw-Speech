# v1.3.0

###### 2026/10/24

* `提示` 指令碼中的 speech.speaker 與兩個說話者工具需要 AutoJs6 6.8.0 正式版或更新版本; "說話者" 頁面與 "只聽主人" 在外掛介面中使用, 不依賴 AutoJs6 的版本. 使用較舊的 AutoJs6 時, 指令碼的 speech.models.list() 會多列出一個類型為 speaker 的說話者辨識模型, 可以照常安裝或刪除
* `新增` 常駐喚醒新增省電模式 (設定 > 常駐喚醒, 預設開啟): 只在聽到說話聲或其他聲音時執行喚醒詞模型, 安靜時不執行, 外掛程式佔用的 CPU 少一半到九成 (周圍越安靜越少); 錄音本身的耗電不變, 所以 Android 估算的耗電只略有減少 (實測見 README). 聲音很輕的喚醒詞可能聽不到, 這時可以關閉省電模式
* `新增` 可下載更多模型: 西班牙語離線辨識 (NeMo, 含標點); 自動判斷語言的八語串流辨識, 涵蓋阿拉伯語, 印尼語, 泰語, 越南語, 日語, 俄語, 中文與英文 (PengChengStarling, 安裝後約 339 MB); Kokoro v1.0 多語言聲音 (英語, 西班牙語, 法語, 印地語, 義大利語, 巴西葡萄牙語與中文共 49 個說話人, 每個說話人念自己的語言); 兩個阿拉伯語聲音與一個韓語聲音. 阿拉伯語與韓語聲音僅限非商業用途, 八語模型的訓練資料未公開, 商業用途未知, 下載前都會提示授權. 新聲音也依語言出現在系統 TTS 引擎中; 系統語音輸入與外掛工具只在其他已安裝模型都不涵蓋某種語言時才自動選用八語模型
* `新增` 說話者辨識與 "只聽主人" (設定 > 常駐喚醒): 在 "說話者" 頁面輸入名字並跟讀 3 句話, 即可註冊自己的聲音 (可以註冊多人, 也可以用試驗證查看分數); 開啟 "只聽主人" 後, 常駐喚醒聽到喚醒詞時先比對聲音, 與已註冊的人相符才開啟面板, 別人說喚醒詞會被忽略. 圖塊, 小工具, 耳機鍵等手動入口不受影響. 需要先下載約 26.5 MB 的說話者辨識模型 (頁面會引導); 聲紋只儲存在本機, 不會上傳或匯出
* `新增` 指令碼可以用 speech.speaker 註冊, 驗證與辨識說話者, 並列出或刪除已註冊的人; 新增外掛工具 speech_speaker_verify (判斷一段錄音是不是某位已註冊的人) 與 speech_speaker_identify (在已註冊的人中找出最像的一位), 結果只有名字與分數, 不含聲紋
* `修復` Android 7.0 上又能下載模型了: 模型目錄與模型檔案都從 GitHub 取得, 其證書現在由 Android 7.0 沒有的根證書 (Let's Encrypt 的 ISRG Root X1) 簽發, 之前每次下載與重新整理目錄都因證書錯誤失敗. 插件現在自帶這張根證書, 與系統自帶的一起使用; Android 7.1 及以上本來就有它, 不受影響

# v1.2.0

###### 2026/10/23

* `提示` 新增常駐喚醒, 預設關閉: 開啟後一直在本機監聽喚醒詞, 麥克風指示燈常亮, 有一則常駐通知, 也更耗電 (關閉螢幕 30 分鐘實測見 README). 建議搭配 "監聽時長" 或 "只在充電時監聽" 使用
* `提示` 指令碼辨識非 WAV 音訊與 4 個外掛工具需要 AutoJs6 6.8.0 正式版或更新版本, 舊版 AutoJs6 的指令碼仍只能辨識 WAV; 常駐喚醒, 新模型, 自動標點與 "檔案" 分頁都在外掛介面中使用, 不依賴 AutoJs6 的版本
* `提示` 新增權限: 喚醒鎖 (只在試聽試說頁辨識檔案時使用, 最長 60 分鐘, 讓關閉螢幕後辨識繼續進行), 媒體處理前景服務 (Android 15 起辨識檔案時使用, 在通知中顯示進度)
* `新增` 常駐喚醒 (設定 > 常駐喚醒): 說出喚醒詞 (預設 "小鹦小鹦" 與 "Hey Macaw", 可修改, 靈敏度分高, 中, 低三段) 即開啟與數位助理相同的聽寫面板; 螢幕關閉或鎖定時也會點亮螢幕, 傳送或複製前先解鎖
* `新增` 由喚醒詞開啟的面板會朗讀辨識出的文字, 有該語言的 3-Macaw Speech 語音時使用它, 否則使用系統語音; 可在設定中關閉
* `新增` 監聽時長 (10, 30, 60 分鐘後自動關閉, 或一直開著) 與只在充電時監聽 (拔掉電源時暫停, 接上後繼續), 與 3-Stove Agent 的同名選項一致
* `新增` 3-Macaw Speech 不是預設數位助理時, 開啟常駐喚醒會詢問一次在其他應用程式上層顯示的權限; 不授予時, 聽到喚醒詞後發出 "點此說話" 通知, 點按即開啟面板
* `新增` 腳本, 其他應用程式或本外掛的其他入口使用麥克風時, 常駐喚醒自動讓出, 對方用完後繼續監聽
* `新增` 與 3-Stone AI 和 3-Stove Agent 的常駐監聽互斥, 系統同一時間只能有一個; 對方開著時會提示先關閉, 並可直接開啟對方的設定
* `新增` 重新開機或更新後不會自動錄音: 開關仍開著時發出一則 "點此恢復常駐喚醒" 通知, 開啟首頁或設定頁也會恢復
* `新增` 辨識音訊檔案 (speech.recognize, speech.detectVoice) 除 WAV 外也支援 MP3, AAC (含 M4A), Ogg (Vorbis, Opus), FLAC, AMR 等常見格式, 以及影片檔案 (MP4, WebM 等) 中的聲音; 檔案上限仍為 200 MB 或 30 分鐘 (需要 AutoJs6 6.8.0 以上, 更早的版本只能傳入 WAV)
* `新增` 4 個外掛工具 (需要 AutoJs6 6.8.0 及以上): speech_listen 聽一句話並傳回文字, speech_speak 朗讀, speech_transcribe 辨識手機上的音訊檔案, speech_synthesize 把文字合成為 WAV 或 M4A 檔案. MCP Server 外掛用它們讓電腦上的 AI 助理透過手機聽和說, 手機上的 3-Stove Agent 可以直接呼叫它們, 指令碼也可以透過 plugins.tools 呼叫; 不能直接錄音時, 聽寫先在手機上發出 "點此說話" 通知, 點按後開始
* `新增` 可下載更多模型: 法語, 俄語與韓語的串流辨識, 以及法語, 西班牙語, 德語與俄語的 Piper 聲音; Piper 聲音與韓語模型僅限非商業用途, 下載前會提示授權, 韓語模型只從上游位址下載
* `新增` 自動標點: 在首頁新的 "標點" 分組中下載標點模型後, 串流模型辨識出的中文與英文會自動加上逗號, 句號與問號, 英文也會恢復大寫; SenseVoice 自帶標點, 不受影響; 指令碼照舊可以傳入 punctuation: false 去掉所有標點
* `新增` 試聽試說頁新增 "檔案" 分頁: 選一個音訊或影片檔案 (MP3, M4A, WAV 等, 不超過 200 MB, 長度不超過 30 分鐘), 不寫指令碼也能辨識出裡面說的話, 依時間分段顯示, 可以複製全文或儲存為文字與 SRT 字幕; 模型, 語言與自動標點在頁面上選; 離開頁面或關閉螢幕後辨識照常進行, 通知中顯示進度並可取消; 最近一次結果下次開啟仍在

# v1.1.0

###### 2026/10/21

* `提示` 新增觸發式入口: 平時不錄音, 點按快速設定圖塊, 主畫面小工具, 捷徑, 懸浮麥克風或按下音量鍵, 藍牙耳機語音鍵後才開啟與數位助理相同的聽寫面板
* `提示` 新增權限: 在其他應用程式上層顯示 (只用於懸浮麥克風, 預設關閉), 開機自動啟動 (只在懸浮麥克風開啟時於重新啟動後恢復它), 特殊用途前景服務 (只保持懸浮麥克風顯示, 不錄音), 鄰近裝置 (Android 12 起只在用耳機語音鍵開啟面板時詢問, 用於接管耳機的語音辨識與麥克風). 按鍵觸發需要在系統無障礙設定中開啟, 只過濾按鍵
* `新增` 快速設定圖塊 (語音指令): 在設定的觸發方式組中加入 (Android 13 起由系統確認, 更早的版本顯示手動步驟), 下拉快速設定點它即可說話; 螢幕鎖定時可以直接聽寫, 傳送或複製前先解鎖 (ColorOS 與 HyperOS 會先要求解鎖); 長按圖塊開啟觸發方式設定
* `新增` 懸浮麥克風: 預設關閉, 開啟時申請在其他應用程式上層顯示的權限; 可沿螢幕邊緣拖曳的圓形按鈕, 點按即可說話; 按鈕本身不錄音, 以一則靜音通知保持顯示 (可在通知中關閉), 開啟時重新啟動後自動恢復; 聽寫面板顯示期間自動隱藏, 可與 3-Stove Agent 的懸浮球同時顯示
* `新增` 主畫面小工具 (按一下說話) 與長按應用程式圖示出現的捷徑 (語音指令) 都開啟聽寫面板; 設定中可以直接把小工具放到主畫面, 主畫面不支援時顯示手動步驟
* `新增` 按鍵觸發: 只過濾按鍵的無障礙服務, 不讀取螢幕內容, 需要在系統無障礙設定中開啟; 預設長按音量下鍵約 0.8 秒開啟聽寫面板, 可改為長按音量上鍵或連按兩下音量下鍵; 短按照常調整音量, 螢幕關閉, 來電或通話時不攔截按鍵
* `新增` 藍牙耳機語音鍵: 長按耳機的語音鍵或觸控區即開啟聽寫面板 (3-Macaw Speech 回應語音指令請求 VOICE_COMMAND). 允許鄰近裝置權限後用耳機麥克風收音, 每次按鍵都有效. 其他應用程式也能回應時, 系統會先讓你選擇. 可在設定的觸發方式群組中關閉耳機語音鍵
* `新增` 各入口開啟的面板與長按電源鍵時相同: 3-Macaw Speech 是預設數位助理時經助理工作階段開啟, 不是時直接開啟同款面板; 系統沒有顯示助理工作階段時 (例如在螢幕鎖定時點圖塊後才解鎖) 也直接開啟面板
* `新增` 打包應用透過獨立入口使用語音辨識與模型管理, 麥克風存取遵循各應用本身的錄音授權
* `修復` 聽寫面板一開啟就開始錄音: 模型仍在載入時 (首次開啟, 或閒置 5 分鐘後) 開頭說的話不再遺失, 你好這樣的短句也不再沒有反應

# v1.0.0

###### 2026/10/20

* `提示` 首個正式版本. 指令碼中的 speech 模組需要 AutoJs6 6.8.0 (5456) 或更高版本; 外掛介面, 系統 TTS 引擎, 系統語音輸入, 語音辨識服務與數位助理不依賴 AutoJs6
* `提示` 辨識與合成模型不隨安裝套件提供, 需要在外掛介面或指令碼中下載; 應用程式整體依 GNU GPL 3.0 或更新版本傳播 (語音執行階段靜態連結了 eSpeak NG), 對應原始碼隨每個發行版提供
* `新增` 作為 AutoJs6 的語音外掛: 在外掛中心啟用後, 指令碼可以透過 speech 模組使用語音辨識, 喚醒詞, 語音活動偵測, 語音合成與模型管理
* `新增` 內建 sherpa-onnx 1.13.8 語音執行環境與 silero VAD v5 語音活動偵測模型, 依 4 種 ABI 分別提供安裝套件
* `新增` 模型管理: 依簽章的模型目錄下載離線語音模型, 優先使用 AutoJs6 共用資源的發布, 無法使用時改用 sherpa-onnx 官方發布; 逐一檔案驗證 SHA-256 後啟用, 支援續傳, 本機匯入 (tar, tar.bz2, zip), 刪除與預設模型, 僅限非商業用途或授權未知的模型需先接受授權
* `新增` 語音辨識: 辨識 WAV 檔案 (8 / 16 / 24 / 32 位元整數或浮點, 任意取樣率與聲道數, 在外掛內重新取樣為 16 kHz 單聲道), 結果按語音段附起訖時間, SenseVoice 模型另附語言, 情緒與事件標籤; 串流模型可使用熱詞
* `新增` 聽寫工作階段: 由外掛錄音或接收 16 kHz PCM, 依序回報就緒, 中間結果, 整句結果, 端點, 語音活動與結束; 可調整斷句靜音時長, 無語音逾時與最長時長; 串流模型逐詞更新中間結果, 離線模型按語音段更新
* `新增` 語音活動偵測: 以內建 silero VAD 列出 WAV 檔案中的語音段
* `新增` 喚醒詞: 開放詞彙的關鍵詞偵測, 中文關鍵詞依常用讀音拼寫為拼音, 英文單字依模型詞典拼寫為音素, 也可以直接寫模型 token; 命中後可在同一錄音上自動轉入一輪聽寫
* `新增` 麥克風工作階段期間外掛以麥克風前景服務與通知持續錄音, 在 AutoJs6 位於前景時開始的工作階段在 AutoJs6 退到背景或螢幕關閉後仍可收音; 同一時間只有一個麥克風工作階段; 缺少麥克風權限時回報 PERMISSION_DENIED 並指出授權頁面
* `新增` 語音合成: 用已安裝的合成模型 (VITS, Matcha 與 Kokoro, 目錄中有 5 種中英文模型) 把最多 8000 個字元的文字逐句合成為 WAV 檔案, 取樣率與模型一致; 可選擇說話者與語速 (0.5 到 2 倍), 依已完成的字元回報進度, 可隨時取消; 只有一位說話者的模型會忽略所選說話者並給出提示
* `新增` 系統 TTS 引擎: 安裝合成模型後, 可在系統的文字轉語音設定中選擇 3-Macaw Speech, AutoJs6 的 tts 模組與其他應用程式都能用它朗讀; 每位說話者對應一個語音, 雙語模型的每位說話者另有一個英文語音, 語速依系統或應用程式的設定; 未安裝模型時引擎回報缺少語音資料
* `新增` 首頁: 顯示語音執行環境版本, 已安裝的模型數量, 麥克風權限 (可一鍵授權), 以及 3-Macaw Speech 是否為偏好的系統 TTS 引擎
* `新增` 首頁的模型依辨識, 喚醒詞, 合成與語音活動偵測分組, 顯示大小, 語言與授權, 可下載, 暫停, 繼續, 取消, 刪除與設為預設; 下載進度同時顯示在通知中; 僅限非商業用途或授權未知的模型需先接受授權, 使用行動數據等計量付費網路下載前會先詢問
* `新增` 從 tar, tar.bz2 或 zip 壓縮檔或資料夾匯入本機模型: 與目錄模型一致的檔案依該模型登記, 其他檔案在填寫種類, 模型類型, 名稱, 語言與 ID 後作為自訂模型匯入
* `新增` 試聽試說: 即時聽寫 (中間結果以灰字顯示), 可切換模型與語言; 喚醒詞試驗列出命中的關鍵詞與分數; 輸入文字後選擇模型, 說話者與語速試聽合成效果, 或儲存為 WAV 檔案; 離開頁面即釋放麥克風
* `新增` 系統語音輸入: 其他應用程式 (例如 3-Stove Agent) 的麥克風按鈕可以使用 3-Macaw Speech 的離線辨識, 在底部面板中說一句話, 辨識出的文字直接交回該應用程式; 停頓後自動結束, 也可以提前停止或取消; 沿用設定頁面的端點靈敏度與語音活動偵測, 不需要時可在設定的辨識群組中關閉
* `新增` 數位助理: 在系統設定中把 3-Macaw Speech 選為預設數位助理應用程式後, 長按電源鍵或 Home 鍵 (或使用助理手勢) 即可在底部面板中說一句話; 辨識出的文字可以編輯, 再點按鈕交給接收語音指令的應用程式 (例如 3-Stove Agent 或 3-Stone AI), 也可以複製或重說; 點按鈕之前不會傳送任何內容. 鎖定畫面時也能使用, 傳送或複製前會先解鎖. 助理不讀取螢幕內容, 平時不在背景收音. 設定的辨識群組會顯示它是否為預設助理, 並可開啟系統設定進行選擇
* `新增` 系統語音辨識服務: 使用 Android 語音辨識介面 (SpeechRecognizer) 的應用程式可以直接指定 3-Macaw Speech, 使用它的離線辨識並取得中間結果; 把它設為預設辨識服務後, 沒有指定的應用程式也會使用它. Android 11 及以下版本選它為數位助理時一般會一併設為預設; Android 12 起需在系統的語音輸入設定中另行選擇 (部分手機沒有這項設定). 其他應用程式 (例如 3-Stone AI) 藉由 3-Macaw Speech 持續監聽喚醒詞時, 數位助理, 系統語音輸入, 語音辨識服務與試聽試說頁仍可使用麥克風: 期間喚醒詞偵測暫停, 結束後自動恢復
