# v1.3.0

###### 2026/10/24

* `힌트` 스크립트의 speech.speaker, speech.diarize, speech.detectLanguage, speech.tag와 화자 및 분석 도구 5개에는 AutoJs6 6.8.0 정식판 이상이 필요합니다. "화자" 페이지, "등록된 목소리만", 체험하기 화면의 파일 분석은 플러그인 안에서 쓰는 기능이라 AutoJs6 버전과 관계없이 쓸 수 있습니다. 이전 AutoJs6에서는 스크립트의 speech.models.list()에 화자 인식, 화자 분할, 언어 식별, 오디오 태그 모델 (종류 speaker, segment, langid, tagger)도 표시되며, 평소처럼 설치하거나 삭제할 수 있습니다
* `기능` 상시 호출어에 절전 모드 추가 (설정 > 상시 호출어, 기본값 켜짐): 말소리나 다른 소리가 들릴 때만 호출어 모델을 실행하고 조용할 때는 실행하지 않아, 플러그인 CPU 시간이 절반에서 10분의 1로 줄어듭니다 (조용할수록 적음). 녹음 자체의 소비는 그대로라서 Android의 추정 소비는 조금만 줄어듭니다 (실측은 README 참고). 아주 작게 말한 호출어는 놓칠 수 있으며, 그럴 때는 절전 모드를 끄세요
* `기능` 내려받을 수 있는 모델 추가: 스페인어 오프라인 인식 (NeMo, 문장 부호 포함), 언어를 자동으로 판별하는 8개 언어 스트리밍 인식 (아랍어, 인도네시아어, 태국어, 베트남어, 일본어, 러시아어, 중국어, 영어, PengChengStarling, 설치 후 약 339 MB), Kokoro v1.0 다국어 음성 (영어, 스페인어, 프랑스어, 힌디어, 이탈리아어, 브라질 포르투갈어, 중국어 화자 49명, 각 화자는 자기 언어를 읽음), 아랍어 음성 2개와 한국어 음성 1개. 아랍어와 한국어 음성은 비상업적 이용만 가능하고, 8개 언어 모델은 학습 데이터가 공개되지 않아 상업적 이용 여부를 알 수 없으며, 모두 내려받기 전에 라이선스를 보여 줍니다. 새 음성은 시스템 TTS 엔진에도 언어별로 나타나며, 시스템 음성 입력과 플러그인 도구는 다른 설치된 모델이 지원하지 않는 언어에만 8개 언어 모델을 자동으로 선택합니다
* `기능` 화자 인식과 "등록된 목소리만" (설정 > 상시 호출어): "화자" 페이지에서 이름을 입력하고 문장 3개를 따라 읽으면 자신의 목소리를 등록할 수 있습니다 (여러 사람을 등록할 수 있고, 인식 시험으로 점수도 볼 수 있습니다). "등록된 목소리만"을 켜면 상시 호출어가 먼저 목소리를 비교해 등록된 사람과 일치할 때만 패널을 열기 때문에, 다른 사람이 호출어를 말하면 무시됩니다. 타일, 위젯, 헤드셋 키 등 수동 실행 방법은 영향을 받지 않습니다. 먼저 화자 인식 모델 (약 26.5 MB)을 내려받아야 하며, 페이지에서 안내합니다. 성문 (목소리 특징)은 기기에만 저장되며 업로드하거나 내보내지 않습니다
* `기능` 스크립트에서 speech.speaker로 화자를 등록, 확인, 식별하고, 등록된 사람을 나열하거나 삭제할 수 있습니다. 새 플러그인 도구 speech_speaker_verify (녹음이 등록된 특정 사람인지)와 speech_speaker_identify (등록된 사람 중 가장 비슷한 사람)를 추가했습니다. 결과에는 이름과 점수만 있고 성문은 없습니다
* `기능` 체험하기 화면의 파일 인식에 분석 3가지를 추가했습니다: 화자 분리 (누가 언제 말했는지 표시하고, 등록된 목소리는 이름도 보여 줍니다. "화자 분리 + 받아쓰기"는 각 사람의 말을 글자로도 옮깁니다), 언어 식별 (Whisper의 99개 언어), 오디오 태그 (사람 목소리, 음악, 개 짖는 소리 등 527종의 소리 중 파일에 있는 것). 모두 휴대폰에서 오프라인으로 처리하며, 화면을 벗어나도 계속되고 진행 상황은 알림에 표시됩니다. 먼저 해당 모델을 내려받아야 하며 화면에서 안내합니다: 화자 분할 모델 약 6 MB (화자 인식 모델도 필요), 언어 식별 모델 약 103 MB, 오디오 태그 모델 약 10.5 MB. 화자 분할 모델은 학습 데이터에 연구용으로만 쓸 수 있는 자료가 있어 비상업적 이용으로 표시하고, 언어 식별 모델은 학습 데이터가 공개되지 않아 상업적 이용 여부를 알 수 없습니다
* `기능` 스크립트에서도 speech.diarize, speech.detectLanguage, speech.tag (Promise를 반환하는 ...Async 버전도 있음)로 같은 분석을 하고 진행 상황을 받을 수 있습니다. 새 플러그인 도구 speech_diarize, speech_detect_language, speech_tag도 추가했습니다. 파일 하나는 최대 30분 (도구의 화자 분리는 10분)이며, 분석은 한 번에 하나만 하고 나머지는 차례를 기다립니다
* `수정` Android 7.0에서 모델을 다시 다운로드할 수 있습니다. 모델 목록과 모델은 GitHub에서 받아오는데, 그 인증서가 이제 Android 7.0에 없는 루트 인증서 (Let's Encrypt의 ISRG Root X1)로 발급되어 다운로드와 목록 새로 고침이 인증서 오류로 매번 실패했습니다. 플러그인이 이 루트 인증서를 직접 포함해 시스템 인증서와 함께 사용합니다. Android 7.1 이상은 원래 갖고 있어 영향이 없습니다

# v1.2.0

###### 2026/10/23

* `힌트` 상시 호출어가 추가되었습니다 (기본값 꺼짐). 켜 두면 기기에서 호출어를 계속 듣고, 마이크 표시등이 켜져 있으며, 알림이 항상 표시되고, 배터리도 더 소모됩니다 (화면을 끈 30분 측정값은 README 참고). "듣기 시간" 또는 "충전 중에만 듣기"와 함께 쓰기를 권장합니다
* `힌트` 스크립트에서 WAV가 아닌 오디오를 인식하는 기능과 플러그인 도구 4개에는 AutoJs6 6.8.0 정식판 이상이 필요합니다. 이전 AutoJs6에서는 스크립트가 여전히 WAV만 인식합니다. 상시 호출어, 새 모델, 자동 문장 부호, "파일" 탭은 플러그인 안에서 쓰는 기능이라 AutoJs6 버전과 관계없이 쓸 수 있습니다
* `힌트` 새 권한: 절전 모드 방지 (체험하기 화면에서 파일을 인식하는 동안에만, 최대 60분, 화면이 꺼져도 인식을 계속하기 위해 사용), 미디어 처리 포그라운드 서비스 (Android 15 이상, 파일 인식 중 알림에 진행 상황 표시)
* `기능` 상시 호출어 (설정 > 상시 호출어): 호출어 (기본값 "小鹦小鹦"과 "Hey Macaw", 변경 가능, 감도는 높음, 보통, 낮음 3단계)를 말하면 디지털 어시스턴트와 같은 받아쓰기 패널이 열립니다. 화면이 꺼져 있거나 잠겨 있어도 화면을 켜며, 보내거나 복사하기 전에 잠금을 해제합니다
* `기능` 호출어로 연 패널은 인식한 텍스트를 읽어 줍니다. 해당 언어의 3-Macaw Speech 음성이 있으면 그것을, 없으면 시스템 음성을 사용하며 설정에서 끌 수 있습니다
* `기능` 듣기 시간 (10, 30, 60분 후 자동으로 끄기 또는 항상 켜 두기)과 충전 중에만 듣기 (전원을 뽑으면 일시 중지하고 다시 연결하면 계속)를 추가했습니다. 3-Stove Agent의 같은 옵션과 동일합니다
* `기능` 3-Macaw Speech가 기본 디지털 어시스턴트가 아니면 상시 호출어를 켤 때 다른 앱 위에 표시 권한을 한 번 묻습니다. 허용하지 않으면 호출어를 들었을 때 "탭하여 말하기" 알림이 표시되고, 누르면 패널이 열립니다
* `기능` 스크립트, 다른 앱 또는 이 플러그인의 다른 실행 방법이 마이크를 쓰면 상시 호출어가 잠시 양보하고, 끝나면 다시 듣습니다
* `기능` 3-Stone AI, 3-Stove Agent의 상시 듣기와는 함께 쓸 수 없습니다 (시스템에서 하나만). 상대가 켜져 있으면 먼저 끄도록 안내하고 상대 앱의 설정을 바로 열 수 있습니다
* `기능` 재시작이나 업데이트 후에는 녹음이 자동으로 시작되지 않습니다. 스위치가 켜져 있으면 "탭하여 상시 호출어 다시 시작" 알림이 표시되며, 홈 화면이나 설정을 열어도 다시 시작됩니다
* `기능` 오디오 파일 인식 (speech.recognize, speech.detectVoice)에서 WAV 외에 MP3, AAC (M4A 포함), Ogg (Vorbis, Opus), FLAC, AMR 등 일반적인 형식과 동영상 파일 (MP4, WebM 등)의 소리도 사용 가능; 제한은 그대로 200 MB 또는 30분 (AutoJs6 6.8.0 이상 필요, 이전 버전은 WAV만 가능)
* `기능` 플러그인 도구 4개 (AutoJs6 6.8.0 이상): speech_listen은 한 문장을 듣고 텍스트를 반환하고, speech_speak는 소리 내어 읽으며, speech_transcribe는 휴대폰의 오디오 파일을 인식하고, speech_synthesize는 텍스트를 WAV 또는 M4A 파일로 합성합니다. MCP Server 플러그인은 이 도구로 컴퓨터의 AI 어시스턴트가 휴대폰을 통해 듣고 말하게 하며, 휴대폰의 3-Stove Agent는 직접, 스크립트에서는 plugins.tools로 호출할 수 있습니다. 바로 녹음할 수 없을 때는 먼저 휴대폰에 "탭하여 말하기" 알림을 띄우고, 누르면 듣기 시작합니다
* `기능` 내려받을 수 있는 모델 추가: 프랑스어, 러시아어, 한국어 스트리밍 인식과 프랑스어, 스페인어, 독일어, 러시아어 Piper 음성. Piper 음성과 한국어 모델은 비상업적 이용만 가능하며 내려받기 전에 라이선스를 보여 주고, 한국어 모델은 원본 주소에서만 내려받습니다
* `기능` 자동 문장 부호: 홈 화면의 새 "문장 부호" 그룹에서 문장 부호 모델을 내려받으면 스트리밍 모델이 인식한 중국어와 영어에 쉼표, 마침표, 물음표가 붙고 영어는 대문자도 복원됩니다. SenseVoice는 자체 문장 부호를 붙이므로 바뀌지 않으며, 스크립트에서 punctuation: false를 넘기면 이전처럼 모든 문장 부호를 없앱니다
* `기능` 체험하기 화면에 "파일" 탭 추가: 오디오나 동영상 파일 (MP3, M4A, WAV 등, 최대 200 MB, 30분)을 고르면 스크립트를 쓰지 않아도 그 안의 말을 글자로 옮겨 시간별로 나누어 보여 주며, 전체를 복사하거나 텍스트와 SRT 자막으로 저장할 수 있습니다. 모델, 언어, 자동 문장 부호는 화면에서 고릅니다. 화면을 떠나거나 화면을 꺼도 인식이 계속되고 알림에 진행 상황과 취소 버튼이 표시되며, 마지막 결과는 다음에 열 때도 남아 있습니다

# v1.1.0

###### 2026/10/21

* `힌트` 실행 방법 추가: 평소에는 녹음하지 않으며, 빠른 설정 타일, 홈 화면 위젯, 바로가기, 플로팅 마이크를 탭하거나 볼륨 키 또는 블루투스 헤드셋의 음성 키를 눌렀을 때만 디지털 어시스턴트와 같은 받아쓰기 패널을 엽니다
* `힌트` 새 권한: 다른 앱 위에 표시 (플로팅 마이크 전용, 기본값 꺼짐), 부팅 시 자동 시작 (켜 둔 플로팅 마이크를 다시 시작한 뒤 되살리는 데만 사용), 특수 용도 포그라운드 서비스 (플로팅 마이크 표시만 유지하며 녹음하지 않음), 근처 기기 (Android 12 이상, 헤드셋 음성 키로 패널을 열 때만 요청하며 헤드셋의 음성 인식과 마이크를 넘겨받는 데 사용). 키 트리거는 시스템 접근성 설정에서 켜며 키 입력만 다룹니다
* `기능` 빠른 설정 타일 (음성 명령): 설정의 실행 방법 그룹에서 추가하고 (Android 13 이상은 시스템이 확인, 이전 버전은 직접 추가하는 방법 표시) 빠른 설정에서 탭하면 바로 말할 수 있습니다. 잠금 화면에서도 바로 받아쓰고 보내거나 복사하기 전에 잠금을 해제합니다 (ColorOS와 HyperOS는 먼저 잠금 해제를 요구). 타일을 길게 누르면 실행 방법 설정이 열립니다
* `기능` 플로팅 마이크: 기본값은 꺼짐이며 켤 때 다른 앱 위에 표시 권한을 요청합니다. 화면 가장자리를 따라 끌 수 있는 둥근 버튼으로, 탭하면 말할 수 있습니다. 버튼 자체는 녹음하지 않고 무음 알림으로 표시를 유지하며 (알림에서 끌 수 있음), 켜 두면 다시 시작한 뒤 자동으로 돌아옵니다. 받아쓰기 패널이 열려 있는 동안 숨겨지며 3-Stove Agent의 플로팅 볼과 함께 표시할 수 있습니다
* `기능` 홈 화면 위젯 (탭하여 말하기)과 앱 아이콘을 길게 누르면 나오는 바로가기 (음성 명령) 모두 받아쓰기 패널을 엽니다. 설정에서 위젯을 홈 화면에 바로 놓을 수 있고, 런처가 지원하지 않으면 직접 추가하는 방법을 보여 줍니다
* `기능` 키 트리거: 키 입력만 다루는 접근성 서비스로 화면 내용을 읽지 않으며 시스템 접근성 설정에서 켭니다. 기본값은 볼륨 낮추기 키를 약 0.8초 길게 눌러 받아쓰기 패널을 여는 것이며, 볼륨 높이기 키 길게 누르기나 볼륨 낮추기 키 두 번 누르기로 바꿀 수 있습니다. 짧게 누르면 평소처럼 볼륨이 바뀌고, 화면이 꺼져 있거나 전화가 오거나 통화 중일 때는 키를 가로채지 않습니다
* `기능` 블루투스 헤드셋 음성 키: 헤드셋의 음성 키나 터치 영역을 길게 누르면 받아쓰기 패널이 열립니다 (3-Macaw Speech가 음성 명령 요청 VOICE_COMMAND에 응답합니다). 근처 기기 권한을 허용하면 헤드셋 마이크로 듣고, 누를 때마다 작동합니다. 다른 앱도 응답할 수 있으면 시스템이 먼저 어떤 앱을 쓸지 묻습니다. 설정의 실행 방법 그룹에서 헤드셋 음성 키를 끌 수 있습니다
* `기능` 모든 입구가 전원 버튼을 길게 눌렀을 때와 같은 패널을 엽니다: 3-Macaw Speech가 기본 디지털 어시스턴트이면 어시스턴트 세션을 거쳐 열고, 아니면 같은 패널을 바로 엽니다. 시스템이 어시스턴트 세션을 표시하지 않을 때 (예: 잠금 화면에서 타일을 탭한 뒤 잠금을 해제한 경우)도 패널을 바로 엽니다
* `기능` 패키징된 앱이 별도 진입점으로 음성 인식과 모델 관리를 사용하며 마이크 접근은 각 앱의 녹음 권한을 따름
* `수정` 받아쓰기 패널이 열리자마자 녹음을 시작합니다. 모델을 불러오는 동안 (처음 열 때, 또는 5분 동안 쓰지 않은 뒤) 처음 한 말이 더 이상 사라지지 않고, 안녕하세요 같은 짧은 말에도 반응합니다

* `힌트` 인식과 합성 모델은 패키지에 포함되지 않으며 플러그인 화면이나 스크립트에서 내려받습니다. 앱 전체는 GNU GPL 3.0 이상으로 배포되며 (음성 런타임이 eSpeak NG를 정적으로 링크하기 때문), 모든 릴리스에 대응 소스 코드가 함께 제공됩니다
* `기능` AutoJs6의 음성 플러그인: 플러그인 센터에서 활성화하면 스크립트가 speech 모듈로 음성 인식, 호출어, 음성 구간 검출, 음성 합성, 모델 관리를 사용할 수 있습니다
* `기능` sherpa-onnx 1.13.8 음성 런타임과 silero VAD v5 음성 구간 감지 모델을 내장하고 4가지 ABI별로 설치 파일 제공
* `기능` 모델 관리: 서명된 모델 카탈로그의 오프라인 음성 모델을 AutoJs6 공유 리소스 릴리스에서 다운로드하고, 사용할 수 없으면 sherpa-onnx 공식 릴리스로 전환합니다. 모든 파일을 SHA-256으로 검증한 뒤 사용하며, 이어받기, 로컬 가져오기 (tar, tar.bz2, zip), 삭제, 기본 모델을 지원합니다. 비상업적 용도로 제한되거나 라이선스가 밝혀지지 않은 모델은 먼저 라이선스에 동의해야 합니다
* `기능` 음성 인식: WAV 파일 (8 / 16 / 24 / 32 비트 정수 또는 부동소수점, 모든 샘플링 레이트와 채널 수, 플러그인 안에서 16 kHz 모노로 리샘플링) 을 인식하고 시작과 끝 시간이 있는 음성 구간을 반환하며, SenseVoice 모델은 언어, 감정, 이벤트 태그도 반환합니다. 스트리밍 모델은 핫워드를 지원합니다
* `기능` 받아쓰기 세션: 플러그인이 직접 녹음하거나 전달받은 16 kHz PCM 으로 준비, 중간 결과, 최종 결과, 끝점, 음성 구간, 종료를 차례로 알립니다. 문장 끝으로 볼 무음 길이, 무음 시간 초과, 최대 시간을 조정할 수 있으며, 스트리밍 모델은 단어마다, 오프라인 모델은 음성 구간마다 중간 결과를 갱신합니다
* `기능` 음성 구간 감지: 내장 silero VAD 로 WAV 파일의 음성 구간을 나열합니다
* `기능` 호출어: 어휘 제한이 없는 키워드 감지입니다. 중국어 키워드는 일반적인 읽기의 병음으로, 영어 단어는 모델 사전의 음소로 표기하며, 모델 토큰을 직접 쓸 수도 있습니다. 감지 후 같은 녹음에서 받아쓰기를 한 번 이어서 할 수 있습니다
* `기능` 마이크 세션 동안 플러그인은 마이크 포그라운드 서비스와 알림으로 녹음을 계속하므로, AutoJs6 가 포그라운드에 있을 때 시작한 세션은 AutoJs6 가 백그라운드로 가거나 화면이 꺼져도 계속됩니다. 마이크 세션은 한 번에 하나만 실행되며, 마이크 권한이 없으면 PERMISSION_DENIED 를 보고하고 권한 화면을 알려 줍니다
* `기능` 음성 합성: 설치된 합성 모델 (VITS, Matcha, Kokoro. 카탈로그에는 중국어와 영어 모델 5 종이 있습니다)로 최대 8000 자의 텍스트를 문장 단위로 WAV 파일에 합성하며, 샘플링 레이트는 모델과 같습니다. 화자와 속도 (0.5 배에서 2 배)를 고를 수 있고, 진행률은 완료된 글자 수로 알리며, 언제든 취소할 수 있습니다. 화자가 한 명인 모델은 선택한 화자를 무시하고 이를 알려 줍니다
* `기능` 시스템 TTS 엔진: 합성 모델을 설치하면 시스템의 텍스트 음성 변환 설정에서 3-Macaw Speech 를 선택할 수 있고, AutoJs6 의 tts 모듈과 다른 앱이 이를 사용해 읽어 줍니다. 화자마다 음성이 하나씩 있고 이중 언어 모델에는 화자마다 영어 음성이 더해지며, 말하기 속도는 시스템 또는 앱 설정을 따릅니다. 설치된 모델이 없으면 엔진은 음성 데이터가 없다고 보고합니다
* `기능` 홈 화면: 음성 런타임 버전, 설치된 모델 수, 마이크 권한 (버튼으로 바로 허용 가능), 3-Macaw Speech 가 시스템의 기본 TTS 엔진인지 여부를 표시합니다
* `기능` 홈 화면의 모델은 인식, 호출어, 합성, 음성 구간 감지로 나뉘어 표시되며 크기, 언어, 라이선스를 확인할 수 있습니다. 다운로드, 일시중지, 재개, 취소, 삭제, 기본값으로 설정을 할 수 있고, 다운로드 진행률은 알림에도 표시됩니다. 비상업적 용도로 제한되거나 라이선스가 밝혀지지 않은 모델은 먼저 라이선스에 동의해야 합니다. 모바일 데이터 같은 종량제 네트워크에서는 다운로드를 시작하기 전에 확인합니다
* `기능` 로컬 모델 가져오기: tar, tar.bz2, zip 압축 파일이나 폴더에서 가져옵니다. 카탈로그의 모델과 일치하는 파일은 그 모델로 등록되고, 그 밖의 파일은 종류, 모델 유형, 이름, 언어, ID 를 입력하면 사용자 모델로 추가됩니다
* `기능` 체험하기: 실시간 받아쓰기 (중간 결과는 회색으로 표시)에서 모델과 언어를 고를 수 있고, 호출어 체험은 감지된 키워드와 점수를 목록으로 보여 줍니다. 입력한 텍스트를 모델, 화자, 속도를 골라 음성으로 합성한 뒤 재생하거나 WAV 파일로 저장할 수 있습니다. 화면을 벗어나면 마이크를 해제합니다
* `기능` 시스템 음성 입력: 3-Stove Agent 등 다른 앱의 마이크 버튼에서 3-Macaw Speech의 오프라인 인식을 사용할 수 있습니다. 하단 패널에서 한 문장을 말하면 인식된 텍스트가 바로 그 앱으로 돌아갑니다; 멈추면 자동으로 끝나며 중간에 중지하거나 취소할 수도 있습니다; 설정의 엔드포인트 민감도와 음성 구간 감지를 따르며, 필요 없으면 설정의 인식 그룹에서 끌 수 있습니다
* `기능` 디지털 어시스턴트: 시스템 설정에서 3-Macaw Speech를 기본 디지털 어시스턴트 앱으로 선택하면 전원 버튼이나 홈 버튼을 길게 누르거나 어시스턴트 동작으로 하단 패널을 열어 한 문장을 말할 수 있습니다. 인식된 텍스트는 편집할 수 있고, 버튼을 눌러 3-Stove Agent나 3-Stone AI처럼 음성 명령을 받는 앱에 넘기거나, 복사하거나, 다시 말할 수 있습니다. 버튼을 누르기 전에는 아무것도 보내지 않습니다. 잠금 화면에서도 사용할 수 있으며 보내거나 복사하기 전에 잠금을 해제합니다. 화면 내용을 읽지 않으며 평소에는 백그라운드에서 듣지 않습니다. 설정의 인식 그룹에서 기본 어시스턴트인지 확인하고 시스템 설정을 열어 선택할 수 있습니다
* `기능` 시스템 음성 인식 서비스: Android 음성 인식(SpeechRecognizer)을 쓰는 앱은 3-Macaw Speech를 직접 지정해 중간 결과와 함께 오프라인 인식을 사용할 수 있으며, 기본 음성 인식 서비스로 설정하면 지정하지 않은 앱도 이를 사용합니다. Android 11 이하에서는 디지털 어시스턴트로 선택하면 보통 기본 서비스로도 설정되고, Android 12부터는 시스템의 음성 입력 설정에서 따로 선택해야 하며, 이 설정이 없는 휴대전화도 있습니다. 다른 앱(예: 3-Stone AI)이 3-Macaw Speech로 호출어를 계속 듣는 동안에도 디지털 어시스턴트, 시스템 음성 입력, 음성 인식 서비스, 체험 화면은 마이크를 사용할 수 있으며, 그동안 호출어 감지는 일시 중지되었다가 끝나면 자동으로 다시 시작됩니다
* `기능` 설정: 언어, 야간 모드, 테마 색상, 런처 아이콘 (기본값은 AutoJs6 따르기). 체험하기 화면과 시스템 TTS 엔진에 쓰이는 기본 인식 모델과 합성 모델, 엔드포인트 민감도, 음성 구간 감지, 화자, 속도, 언어별 기본 음성 (스크립트는 문서에 나온 기본값을 그대로 사용). 유휴 모델을 해제하는 시간, 모델 카탈로그 새로 고침, 남은 파일 정리. 시스템의 텍스트 음성 변환 설정에서 3-Macaw Speech 의 설정 버튼을 누르면 이 화면이 열립니다
